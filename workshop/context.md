# Workshop context

## Background

Jasper Fülle is an external IT consultant from Netlight working as a software developer on a Eurowings Digital (EWD) project. He volunteered to run this AI-enablement session as part of the AI Focus Days.

Participation is voluntary. Developers' experience with coding agents varies: some are power users and some have never used them, and some colleagues are skeptical of AI altogether. Because the session is voluntary, those who don't want to engage with AI will mostly stay away, so the audience will likely lean toward people who are interested and already use AI. At the same time, the invitation's title (“Your First Steps”) and wording address people with little or no experience, as well as designers, product owners, and curious colleagues from other departments. Expect a mixed room.

Jasper wants the session to be beginner-friendly without being beginner-centered. It should be substantive for experienced participants while requiring no prior coding-agent experience. It is also an opportunity to show what a Netlight consultant brings: a clear point of view, opinionated practice, and honest experience in framing problems, facilitating decisions, and evaluating evidence. Explaining AI terminology or tool features (such as what a skill is) does not demonstrate that value; participants don't need a consultancy for it.

## Session direction

**Thesis:** Writing code got cheap. Deciding what to build, checking that it's right and owning the result did not. That is where the human work moves when an agent writes the code.

The session supports the thesis with one real change, made live in one local GitHub Copilot CLI session:

1. Clarify the request with the audience and the `grill-me` skill (interview first, not prompt first).
2. Let the agent record the agreed scope, behavior and test seam in the GitHub issue, and approve it as a group.
3. Implement test-first with the `tdd` skill; the room confirms the test seams, and the facilitator approves commands. Discuss how agents game tests and how agreed seams prevent it.
4. Let the agent open a PR, review it against the issue and the audience's predictions, then decide what happens next.

It then zooms out: skills as team knowledge, one honest lesson from Jasper's own project work, and a concrete next step for every level on an experience ladder.

Every part has two layers: a one-sentence entry point for newcomers and a deeper point for people already using agents. The demo stays simple; the depth comes from the commentary. The agent does the work; people decide what it should do and whether it is done. The facilitator operates the tools; participants contribute decisions, predictions, and a review verdict. The session should stay aligned with the invitation and not imply that a generated PR is automatically correct or ready to merge.
